the image

Four layers, one artifact

Each instruction in the Dockerfile adds a cached layer. Change the HTML and only that layer rebuilds — everything below it is reused.

FROM nginx:alpine base image
RUN rm -rf /usr/share/nginx/html/* clean root
COPY index.html /usr/share/nginx/html/ your code
EXPOSE 80 network
CMD ["nginx", "-g", "daemon off;"] entrypoint
